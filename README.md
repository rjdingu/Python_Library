# Python Library Basics

This repository contains beginner-friendly examples and practice notebooks for three essential Python libraries used in Data Science and Machine Learning:

- NumPy
- Pandas
- Matplotlib

The notebooks demonstrate fundamental concepts, basic operations, and simple examples to help students understand these libraries.

## Repository Contents

### 📊 NumPy
File: `Numpy.ipynb`

Topics covered:
- Creating arrays
- Array indexing and slicing
- Mathematical operations
- Statistical functions
- Reshaping arrays

### 🐼 Pandas
Files:
- `Pandas.ipynb`
- `Basics_Pandas.ipynb`

Topics covered:
- Series and DataFrames
- Reading CSV files
- Data selection and filtering
- Data cleaning
- Basic data analysis

### 📈 Matplotlib
File: `Matplolib.ipynb`

Topics covered:
- Line plots
- Bar charts
- Histograms
- Labels and titles
- Data visualization basics

### 📂 Dataset
File: `Salary Data.csv`

Used for demonstrating:
- Data loading with Pandas
- Basic analysis
- Visualization examples

## Technologies Used

- Python 3
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook
